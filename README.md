## 🎯 Overview

Orange Factory B2B is a modern wholesale platform designed for international buyers seeking high-quality Korean fashion products. Built with Next.js 15 App Router and Supabase backend.

## ✨ Features

- 🌍 **Multi-language Support** - Korean, English, Japanese, Chinese
- 🏪 **Seller Marketplace** - Verified manufacturer listings
- 📦 **Product Catalog** - Comprehensive inventory management
- 💼 **B2B Inquiry System** - Direct communication with sellers
- 📊 **Dashboard Analytics** - Sales and traffic insights
- 🔐 **Secure Authentication** - Supabase Auth integration

## 🛠 Tech Stack

| Category | Technology |
|----------|------------|
| Framework | Next.js 15 (App Router) |
| Language | TypeScript 5.0 |
| Styling | Tailwind CSS + shadcn/ui |
| Backend | Supabase (PostgreSQL) |
| Auth | Supabase Auth |
| Hosting | Vercel |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/kks0488/B2Borangefactory.git

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Run development server
npm run dev
```

## 📁 Project Structure
